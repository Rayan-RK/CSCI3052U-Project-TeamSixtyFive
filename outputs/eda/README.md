# Milestone 2 measured EDA evidence

Generated by `notebooks/01_eda_eurosat.ipynb` from the complete official EuroSAT v2 archives. Read the approval memo for interpretation and limitations.

- `class_counts.csv`, `rgb_class_counts.png`, `ms_class_counts.png`: observed counts per representation.
- `rgb_samples.png`, `ms_samples.png`: labeled representative images; MS uses display-only contrast stretching.
- `file_checks.csv`: per-file decoding, shape, nodata and non-finite checks.
- `channel_statistics.csv`: descriptive pixel-weighted population statistics, not fitted model preprocessing.
- `archive_verification.csv`: source checksums and extraction-to-archive comparisons.
- `geotiff_metadata.csv`: CRS, bounds, transforms and candidate WGS84 centers.
- `preliminary_region_manifest.csv`, `geographic_coverage.png`: provisional country/region coverage, not finalized training/test assignments.
- `provenance.json`: data sources, region convention, boundary checksum and measured software versions.

Raw data is intentionally excluded from Git. Reproduce with `python src/download_eurosat.py`, then run all notebook cells. Boundary definitions and coastline approximations can affect the screening; review flagged samples and establish buffered geographic groups before modelling.
