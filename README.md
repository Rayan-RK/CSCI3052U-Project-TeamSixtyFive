# Out-of-Distribution Generalization in Satellite Land Cover Classification: A Geographic Domain-Shift Approach

**Course:** CSCI 3052U — Machine Learning I  
**Team:** Team SixtyFive.AI  

## Project Overview
Investigating the structural fragility and performance degradation ($\Delta \text{Macro-}F_1$) of computer vision models under geographic domain shifts using the EuroSAT Sentinel-2 dataset.

## Repository Structure
* `reports/` — Contains Milestone proposals, team contracts, and Milestone 2 approval documentation.
* `notebooks/` — Jupyter notebooks for Exploratory Data Analysis (EDA) and metadata inspection (`01_eda_eurosat.ipynb`).
* `src/` — Modular Python scripts for data pipelines, baselines, and CNN training.
* `outputs/` — Measured EDA evidence, summary data tables (CSV), metadata logs, and generated figures/plots.
