# Out-of-Distribution Generalization in Satellite Land Cover Classification
**Course:** CSCI 3052U - Machine Learning I  
**Team:** Team SixtyFive.AI  

## Project Overview
Investigating the structural fragility and performance degradation ($\Delta$ Macro-$F_1$) of computer vision models under geographic domain shifts using the EuroSAT Sentinel-2 dataset.

## Repository Structure
- `reports/` — Contains Milestone proposals, team contracts, and Milestone 2 approval memos.
- `notebooks/` — Jupyter notebooks for Exploratory Data Analysis (EDA) and prototyping.
- `src/` — Modular Python scripts for data pipelines, baselines, and CNN training.
